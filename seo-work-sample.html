How it was audited

  • Crawled and parsed all 283 pages: titles, meta descriptions, heading order, canonicals, viewport, lang and og tags checked on every page rather than a sample.
  • Resolved every internal link in the site — 23,119 of them — against the file tree to find broken links and orphan pages.
  • Validated all 349 JSON-LD blocks with a real parser; added BreadcrumbList sitewide and Organization/WebSite with a working SearchAction.
  • Measured Core Web Vitals in a real 390px mobile viewport using PerformanceObserver, and traced each layout shift to the element that caused it.
  • Verified sitemap.xml against the actual page count and confirmed robots.txt.

Also delivered

  • Keyword research and mapping across 6 categories and 52 subcategories, one primary intent per page, no stuffing.
  • 15 original long-form guides written as the site's supporting content, each linked into the relevant category pages.
  • Client-facing audit report documenting method, findings and fixes.

Scope, stated plainly

This is a new site with no ranking or traffic history yet. The improvements above are technical and on-page, measured directly against the build. Search Console submission and analytics are the next step, after which ranking and traffic data will exist. I would rather show what was actually measured than present numbers I do not have.
